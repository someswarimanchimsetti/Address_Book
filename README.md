# Address Book Management System

## Overview
A console-based Address Book Management System developed using C. It allows users to manage contact information through a simple menu-driven interface.

## Features
- Create new contacts
- Search for existing contacts
- Edit contact details
- Delete contacts
- Display all saved contacts
- Save and load contact information using file handling
- Validate user inputs

## Technologies Used
- Programming Language: C
- Concepts: Structures, Pointers, File Handling, Modular Programming
- Build Tool: GCC and Makefile
- Platform: Linux

## Compilation

Compile the project using:

```bash
make
```

Run the application:

```bash
./address_book
```
